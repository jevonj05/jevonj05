# Student Budget AI 💸

## Overview
Student Budget AI is a web-based budgeting application designed for college students to manage their finances effectively. The app allows users to track expenses, set monthly budgets, and receive personalized financial advice powered by AI.

This project combines full-stack web development with artificial intelligence to create a practical, real-world solution for student money management.

---

## Features

### 🔐 User Authentication
- Secure registration and login system
- Passwords are hashed for security

### 💰 Budget Management
- Set monthly income and spending limits
- Track remaining budget and income in real-time

### 📊 Expense Tracking
- Add, view, and delete expenses
- Categorize spending (food, transportation, etc.)
- View recent transactions

### 📈 Dashboard Analytics
- Total spending for the month
- Number of transactions
- Number of spending categories
- Budget alerts (safe, warning, overspending)

### 🤖 AI Budget Coach (Gemini API)
- Ask financial questions
- Receive personalized advice based on:
  - Your income
  - Your spending habits
  - Your recent expenses
- Designed specifically for student budgeting
