## Featured Projects

### 🤖 Homelab Sysadmin AI — In Development
A local AI-assisted system administration project designed to monitor and troubleshoot a Linux homelab. The project combines Python-based health checks, Docker diagnostics, network testing, safe command execution, and a locally hosted LLM through Ollama.

**Focus:** Python • Linux • Docker • Ollama • Automation • System Monitoring • AI

Current capabilities being developed include:
- Disk, system, Docker, and network health checks
- Structured diagnostic output for an AI assistant
- Local LLM analysis with Qwen through Ollama
- Controlled command execution
- Automated troubleshooting workflows
- Modular checks that can be expanded as the homelab grows

*A dedicated public repository and technical documentation are being prepared as development continues.*
